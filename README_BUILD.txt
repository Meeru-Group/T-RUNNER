THANVI GAME DEV — T RUNNER Android project
Package: com.thanvigamedev.trunner
Version: 1.0.0 (versionCode 1)
Orientation: Landscape
Network permission: none
Game runtime: local Android WebView loading app/src/main/assets/index.html
Storage: browser localStorage on this device for best score
Branding: custom blue-and-gold THANVI emblem used for launcher icon, splash screen and game menu
Server/VPS/database: not required

BUILD REQUIREMENTS
- Android Studio
- Android SDK Platform 35
- JDK 17
- Gradle compatible with Android Gradle Plugin 8.7.3 (Gradle 8.9 recommended)

BUILD
1. Extract this ZIP.
2. Open the extracted THANVI_T_RUNNER_Android_Project folder in Android Studio.
3. Allow Gradle sync to complete.
4. Build > Build Bundle(s) / APK(s) > Build APK(s).
5. For Play Store AAB: Build > Generate Signed Bundle / APK > Android App Bundle.
6. Create and safely back up your signing key. Never share the keystore or passwords.
7. Install the debug APK on your phone and test gameplay, pause, score persistence, rotation and app restart.

IMPORTANT
This is Android Studio source code, not a precompiled APK. It has not been compiled or device-tested in this environment. The earlier HTML game project is included as local assets. No internet permission is declared, so the app itself does not need network access.
